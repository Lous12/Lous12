### 📚 [WorldBox Modding Docs](https://github.com/Lous12/worldbox-modding-docs)

Community-driven technical documentation, research, examples and troubleshooting for **WorldBox modding** and **NeoModLoader**.

The project is built from real mods, runtime experiments, source archaeology, reproducible failures and compatibility testing.

**Links:** [Documentation](https://lous12.github.io/worldbox-modding-docs/) · [Repository](https://github.com/Lous12/worldbox-modding-docs)

### 🧪 WorldBox Modding Lab

A research suite used to test undocumented or uncertain WorldBox/NML behavior with minimal reproducible probes.

Research results are promoted into **WorldBox Modding Docs** only after evidence is collected from real runtime tests and logs.

Current research includes save/load persistence, world isolation, lifecycle behavior, Harmony/reflection, UI, localization and world generation.
