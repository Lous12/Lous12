## 🌍 WorldBox projects

### 🏛️ [Political World](https://github.com/Lous12/PoliticalWorld)

A political overhaul and addon framework for **WorldBox** and **NeoModLoader**.

Ideologies, parties, governments, elections, crises, international blocs, political map modes, public API, addon SDK and more.

> **Status:** maintenance / active development paused.  
> Source code is public and forks, addons, experiments and pull requests are welcome.

**Links:** [Website](https://lous12.github.io/PoliticalWorld/) · [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3780484869) · [Repository](https://github.com/Lous12/PoliticalWorld)

**Tech:** C# · NeoModLoader · Harmony · WorldBox modding

---

### ♟️ [Political World: Grand Strategy](https://github.com/Lous12/PoliticalWorld-GrandStrategy)

Experimental addon for **Political World** with a more grand-strategy-style political interface and additional high-level systems.

The current public snapshot includes political overview UI, ideology and party presentation, National Spirits, Government Agendas, political-event notifications and other experiments.

> **Status:** development paused.  
> The latest development snapshot and full source code are public for forks and continuation.

**Repository:** [PoliticalWorld-GrandStrategy](https://github.com/Lous12/PoliticalWorld-GrandStrategy)

---

### 📦 [TradeBox](https://github.com/Lous12/TradeBox)

Experimental standalone economy and trade expansion for **WorldBox**.

TradeBox works with real vanilla city resources and was designed around reserves, shortages, prosperity and internal trade. Planned systems included markets, visible caravans, international trade, monopolies, economic systems and optional Political World integration through a separate addon.

> **Status:** unfinished / development paused.  
> The latest working development snapshot, source code and original project plans are public.

**Repository:** [TradeBox](https://github.com/Lous12/TradeBox)

## 📚 Documentation & research

### [WorldBox Modding Docs](https://github.com/Lous12/worldbox-modding-docs)

Community-driven technical documentation, research, examples and troubleshooting for **WorldBox modding** and **NeoModLoader**.

Built from real mods, runtime experiments, source archaeology, reproducible failures and compatibility testing.

**Links:** [Documentation](https://lous12.github.io/worldbox-modding-docs/) · [Repository](https://github.com/Lous12/worldbox-modding-docs)

**Tech:** Astro · Starlight · MDX · GitHub Pages

### 🧪 WorldBox Modding Lab

A collection of small reproducible experiments used to investigate undocumented or uncertain WorldBox/NML behavior.

Research covers save/load persistence, lifecycle behavior, Harmony/reflection, UI, localization, world generation and other modding edge cases.
